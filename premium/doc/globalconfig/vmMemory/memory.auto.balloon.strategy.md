
## Name

```
memory.auto.balloon.strategy(内存回收策略)
```

### Description

```
memory auto balloon strategy
```

### 含义

```
内存回收策略，IdleFirst：优先回收空闲内存，UrgentFirst：优先回收紧急内存，All：应用所有策略
```

### Type

```
java.lang.String
```

### Category

```
vmMemory
```

### 取值范围
