
## Name

```
vm.metadata.enabled(云主机元数据功能开关)
```

### Description

```
enable vm metadata
```

### 含义

```
控制是否启用云主机元数据持久化功能。开启后，系统自动将云主机配置元数据（CPU、内存、磁盘、网络、快照树等）序列化为JSON并写入主存储，用于灾难恢复场景下的云主机重建
```

### Type

```
java.lang.Boolean
```

### Category

```
vm
```

### 取值范围

```
{true, false}
```

### 取值范围补充说明

```
true：启用元数据持久化，API操作完成后自动触发脏标记和异步刷盘
false：禁用，所有后台任务和拦截器均不做处理
```

### DefaultValue

```
false
```

### 默认值补充说明

```
默认关闭，需管理员评估主存储写入开销后手动开启
```

### 支持的资源级配置



### 资源粒度说明

```
无
```

### 背景信息

```
云主机元数据持久化功能，将VM完整配置以JSON格式写入主存储。当主存储可用但管理节点数据库丢失时，可通过主存储上的元数据文件重建云主机。该功能有一定主存储IO开销，因此默认关闭
```

## 注意事项

```
该配置为全局总开关，关闭后所有元数据相关后台任务（Poller、维护任务）停止，已有脏标记行不会被处理，直到重新开启
```
