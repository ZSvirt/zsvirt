
## Name

```
image.expiration.time(镜像过期时间)
```

### Description

```
the expiration time in seconds of an image so it can be purged when it is stale.
```

### 含义

```
镜像被放入回收站后的过期时间
```

## 注意事项

```
当镜像过期后，才能被定时任务或者手动清理掉，否则只能手动强制清理，设置为0代表镜像不会被放入回收站，会被直接永久性删除
```
