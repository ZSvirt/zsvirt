
## Name

```
upload.max.idle.duration.in.seconds(上传镜像最大等待时长)
```

### Description

```
the max duration can be tolerated when uploading images, in seconds
```

### 含义

```
上传镜像时最大的等待时间，单位：秒
当上传镜像任务开启后，如果太长时间没有上传数据，该任务会暂停或失败
```
