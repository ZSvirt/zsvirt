
## Name

```
vm.metadata.flush.concurrency(元数据刷盘并发数)
```

### Description

```
Max concurrent metadata flush tasks per management node
```

### 含义

```
控制每个管理节点同时执行的元数据刷盘任务数上限。当在途刷盘任务数达到此值时，新请求会被节流释放
```

### Type

```
java.lang.Integer
```

### Category

```
vm
```

### 取值范围

```
[0, 100]
```

### 取值范围补充说明

```
值越大并发写入主存储压力越高，建议根据主存储IOPS能力调整
```

### DefaultValue

```
10
```

### 默认值补充说明

```
默认10个并发刷盘任务，适用于大多数主存储类型
```

### 支持的资源级配置



### 资源粒度说明

```
无
```

### 背景信息

```
元数据刷盘需要向主存储发送写入命令。过高的并发数会造成主存储压力，过低则影响大规模脏行的收敛速度。该参数实时生效，无需重启
```

### UI暴露

```
暴露
```

### CLI手册暴露

```
暴露
```

## 注意事项

```
该值为单管理节点上限，多管理节点环境下实际全局并发数 = 该值 × 管理节点数
```
