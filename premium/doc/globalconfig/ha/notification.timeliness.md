
## Name

```
notification.timeliness(##中文名-必填##)
```

### Description

```
Timeliness of HA notification. Configuration value should between -1 and 5. VM HA process will be notified to system endpoint,
            Negative value means notification disabled. The lower the value, the more promptly notify. The higher the value,
            the more expired notification will be ignored.
```
