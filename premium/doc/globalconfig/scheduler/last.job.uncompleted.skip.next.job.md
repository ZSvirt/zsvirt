
## Name

```
last.job.uncompleted.skip.next.job(定时任务触发时上一个任务未完成则跳过下一个任务)
```

### Description

```
skip next job when the last job is not completed
```

### 含义

```
设置为true，定时任务触发时，上一个任务未完成，跳过下一个任务；
设置为false，定时任务触发时，上一个任务未完成，继续下一个任务。
```

### Type

```
java.lang.Boolean
```

### Category

```
scheduler
```
