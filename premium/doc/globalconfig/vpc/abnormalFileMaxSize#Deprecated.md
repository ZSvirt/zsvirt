
## Name

```
abnormalFileMaxSize(VPC内异常文件报警临界值)
```

### Description

```
the max size of abnormal file that will not report abnormal files in vpc
```

### 含义

```
设置VPC内文件异常临界值，当大小大于所设置的临界值，则有可能触发平台报警
```
