
## Name

```
vm.metadata.lastRefreshVersion(元数据升级刷新版本号)
```

### Description

```
Last completed upgrade refresh version, prevents duplicate triggers across MNs. Internal use only
```

### 含义

```
记录上一次完成升级全量刷新时的版本号。管理节点启动时如果当前版本高于该值，会触发全量刷新；刷新完成后更新此值，防止多管理节点重复触发。仅供系统内部使用
```

### Type

```
java.lang.String
```

### Category

```
vm
```

### 取值范围

```
[-9223372036854775808, 9223372036854775807]
```

### 取值范围补充说明

```
系统自动管理的版本号字符串，用户不应手动修改
```

### DefaultValue

```
5.0.0
```

### 默认值补充说明

```
初始值为5.0.0，表示尚未执行过升级刷新。首次开启元数据功能并升级后，系统自动将此值更新为当前版本
```

### 支持的资源级配置



### 资源粒度说明

```
无
```

### 背景信息

```
ZStack版本升级后元数据序列化格式可能变化，需对所有云主机重新生成元数据。此配置记录已完成刷新的版本，避免多管理节点重复触发全量刷新
```

### UI暴露

```
不暴露
```

### CLI手册暴露

```
不暴露
```

## 注意事项

```
仅供系统内部使用，请勿手动修改。手动修改可能导致升级后全量刷新被跳过或重复执行
```
