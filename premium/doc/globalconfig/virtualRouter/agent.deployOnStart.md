
## Name

```
agent.deployOnStart(##中文名-必填##)
```

### Description

```
A boolean value. When set to true, management server will deploy virtual router agent every time a virtual router being created/started/reboot, using ansible. The  virtual router image has agent built in by default, so in most of time this value doesn't need setting to true, as it will significantly increase boot time of virtual router; however, in case you have a new agent needed deploying in an existing virtual router, set this value to true and reboot virtual router will do the work.
```
