
## Name

```
update.os.parallelismDegree(升级操作系统或云平台依赖包的并发度)
```

### Description

```
The maximum count of cluster that can update operating system at the same time
```

### 含义

```
相同集群同时运行升级操作系统或云平台依赖包的最大物理机数量
```

### Type

```
java.lang.Integer
```

### Category

```
cluster
```

### 取值范围

```
[-2147483648, 2147483647]
```

### 取值范围补充说明

```

```
