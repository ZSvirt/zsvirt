
## Name

```
zstore.allow.ports(##中文名-必填##)
```

### Description

```
tcp or udp ports allowed by zstore, udp port start with 'u' like 'u67', port range can be like this: 1100:1200, multiple port or port range can be separated by ”,“
```

### 含义

```
配置imagestore agent允许放行的端口
```

```
java.lang.String
```
