
## Name

```
vm.edk.version(虚拟机下次启动时使用的EDK版本)
```

### Description

```
Specify the EDK version to be used for the next VM startup. None indicates the use of the system's default EDK version
```

### 含义

```
指定在下一次启动的虚拟机中使用的EDK版本。
```
