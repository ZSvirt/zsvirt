
## Name

```
resNotify.enable(资源变更通知开关)
```

### Description

```
enable resource change notification
```

### 含义

```
是否启用资源变更通知。启用后，系统会监听资源创建、更新、删除事件，并向匹配的资源通知订阅发送 webhook 通知。
```

### Type

```
java.lang.Boolean
```

### Category

```
zwatch
```

### 取值范围

```
[-9223372036854775808, 9223372036854775807]
```

### 取值范围补充说明

```
true 表示启用资源变更通知；false 表示关闭资源变更通知。
```

### DefaultValue

```
false
```

### 默认值补充说明

```
默认关闭，避免未配置订阅时产生额外的资源生命周期监听和 webhook 投递行为。
```

### 支持的资源级配置



### 资源粒度说明

```
无
```

### 背景信息

```
用于支持外部系统通过 webhook 订阅资源变更事件，并实时同步资产资源信息。
```

### UI暴露

```
否
```

### CLI手册暴露

```
否
```

## 注意事项

```
启用前请确保已创建资源通知订阅，并保证订阅中的 webhook 地址可以被管理节点访问。
```
