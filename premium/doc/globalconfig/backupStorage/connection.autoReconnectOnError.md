
## Name

```
connection.autoReconnectOnError(本地备份服务器自动重连)
```

### Description

```
A boolean value indicating whether management server automatically starts a reconnect if a backup storage ping command fails
```

### 含义

```
默认为true，用于设置本地备份服务器失联时，是否开启自动重连。true表示开启自动重连。
```

java.lang.Boolean
