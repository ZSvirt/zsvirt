
## Name

```
vm.cpu.quota(cpu配额)
```

### Description

```

```

### 含义

```
配置单位时间段（1000000ms）内CPU的配额以达到CPU限制的功能
```

### Type

```
java.lang.Long
```

### Category

```
kvm
```

### 取值范围

```
[10000, 1000000]
```

### 取值范围补充说明

```
无
```

### DefaultValue

```
1000000
```

### 默认值补充说明

```
在单位时间内（1000000ms）给虚拟机CPU的配额为1000000ms，即不进行CPU限制
```

### 支持的资源级配置

||
|---|
|org.zstack.header.vm.VmInstanceVO

### 资源粒度说明

```
全局粒度，VM级别粒度
```

### 背景信息

```
增强CPU限制能力：主要配置cputune中的period和quota字段，以控制在指定周期内vCPU可以利用的时间，周期以微秒为单位进行测量。
通常，将周期固定为1,000,000微秒。例如为了实施CPU服务质量（QoS）限制，将最大CPU频率使用限制在23%，将quota设置为230,000。
```
