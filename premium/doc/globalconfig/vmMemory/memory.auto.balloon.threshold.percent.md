
## Name

```
memory.auto.balloon.threshold.percent(内存回收阈值)
```

### Description

```
memory auto balloon threshold to avoid frequent balloon
```

### 含义

```
内存回收阈值，当内存回收后，内存的变化范围符合该阈值时，不再进行内存回收，单位为百分比
```

### Type

```
java.lang.String
```

### Category

```
vmMemory
```

### 取值范围

```
[0 ,100]
```
