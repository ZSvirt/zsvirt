
## Name

```
auto.rollback(配置失败自动删除实例vm)
```

### Description

```
auto delete applianceVm when created failed, auto stop applianceVm when start/reboot failed.
```

### 含义

```
创建applianceVm，包含创建vm和配置applianceVm。失败，是否自动删除VM。
启动/重启applianceVm，包含启动/重启vm和配置applianceVm。失败，是否自动停止VM
```
